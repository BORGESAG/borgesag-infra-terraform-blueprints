# Blueprints

Opinionated compositions of modules for one provider and one pattern:
`blueprints/<provider>/<pattern>/`.

Planned patterns per provider: landing zone, network (hub-spoke, VCN, VPC), Kubernetes
cluster (AKS, EKS, GKE, OKE, kubeadm on Proxmox), virtual machines, managed database,
storage with backup, identity.

Each blueprint README states the frameworks it maps to (`docs/frameworks.md`), its
validation level and the example that exercises it.
